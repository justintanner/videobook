# Command Reference

Every current MCP endpoint and discoverable action is listed once. Use the Actions button on any screen, press Ctrl+Shift+K / Cmd+Shift+K, or type a slash in chat to browse the complete catalog. Search includes aliases and descriptions. A command with missing arguments opens its form; media, notebook, entity, track and clip selectors provide targets. Advanced provider alternatives retain shared input fields and show a cost review before generation.

Media commands `/export`, `/delete`, `/reverse` and `/trim` target media. Sequence operations use `/export-sequence`, `/clip-delete`, `/clip-reverse`, `/clip-trim`, and `/clip-audio`; clip timing uses frames and media trimming uses seconds. `/clip-audio` edits gain, mute, and fades on an audio-track clip. Explicit legacy clip IDs and `/export @sequence-main` remain accepted. Use grid addresses such as `/crop @a1`, `/trim @a1 0 2` or `/insert @a1 0 60`.

Image, video and audio generation runs through `generate_image`, `generate_video` and `generate_audio` with a model id from `list_generation_models`; see [generation-models.md](generation-models.md). Slash aliases match their canonical action in search. The legacy `/skeleton` shortcut opens a reviewed AI pose-guide request. Import owns upload transport and duplicate-byte checks; it uses a native file picker. Set `VIDEOBOOK_DOWNLOADS_DIR` to override the server's default Downloads directory.

Routine pointer actions return focus to chat. Editing fields, open dialogs, keyboard navigation and native playback retain focus. Closing a dialog restores its opener when appropriate; delayed work cannot take focus from a newer edit.

## MCP endpoints (215)

- `add_sequence_track` — Append a canonical video, audio, or caption track
- `analyze_editing_moments` — Analyze footage for editing in a background job: shot boundaries, per-shot motion, subject changes, usable ranges and ranked source moments, reused for unchanged sources. Read the results with get_editing_moments.
- `analyze_image_subjects` — Automatically decompose an image into cached subjects using Seedream 5 Pro
- `analyze_jokes` — Find and classify the jokes in a clip from its ElevenLabs transcript (verbatim text, start and end times, why each works) in a background job. Run transcribe first when there is no transcript. Returns status cached with the earlier jokes when the current transcript was already analysed; pass force to analyse again.
- `analyze_music` — Analyze an audio source's beats and waveform locally in a background job, reusing results for unchanged audio. sections adds an energy curve and suggested section boundaries and labels, which may use a paid model.
- `analyze_video` — Analyze a video with vision and its transcript in a background job: summary, scenes, tags, subjects, and burned-in subtitles or watermarks. The analysis appears on the asset when the job finishes. Returns status cached when the current video and transcript were already analysed; a repeated or concurrent request joins the running job.
- `animate_keywords` — Turn transcript-timed keyword titles on or off for a video's renders, placed by vision away from faces, subtitles and on-screen text. Pass keywords for exact transcript words, or omit them for automatic picks.
- `apply_sfx` — Generate ElevenLabs sound effects and mix them into a video's audio in place, one cue per entry at its timestamp and duration. Get entries from suggest_sfx.
- `apply_watermark` — Burn the X or TikTok handle and an optional positioned QR code (off by default), or the platform's saved watermark template, onto a video in place, each with its own opacity, padding and visibility window. wait=false returns once the burn is queued. mode=overlay stores a legacy render-time overlay instead.
- `archive_clip` — Save a URL or a video or audio asset to the global clip archive (B2 when configured, otherwise local), deduplicated by content and transcribed; restore it with restore_archive_clips.
- `assemble_goal` — Append a reviewed goal's completed video-stage clips in order to the sequence. Used by Goal mode for multi-clip plans; single-clip goals need no assembly.
- `asset_history` — Get immutable Dolt revision history for an asset

- `attach_library_asset` — Copy a foreign Library asset into a book and attach it to a media slot
- `audio_boost` — Boost audio volume of a video or audio asset using a linear multiplier (1.0–4.0). Operates in-place with git versioning.
- `audio_mix` — Mix a video or audio layer asset into a target video or audio asset in place, starting at 0 seconds at volume 0-100; the target keeps its duration and picture.
- `backfill_asset_tags` — Tag the assets already in a book. 'start' adopts cached analysis; allow_analysis permits provider calls. Pause and cancel stop new work; already queued analysis may finish. Resume continues saved progress.
- `book_archive` — Local export-book/import-book CLI coordination: prepare a consistent snapshot, reserve an import workspace, adopt a validated book, or release scratch files. Archive bytes stay on the local filesystem.
- `cancel_job` — Cancel a queued or running persistent job by job_id. For a leftover provider task after local jobs have finished, pass asset_id and its expected_task_id to cancel local tracking and retain media; this does not cancel the request at the provider.
- `caption_video` — Subtitles for a video in the TikTok style: read the editable draft and its preparation status, prepare word-timed transcription with vocal timing and face/text placement, save word, timing, phrase, position and style edits against the draft revision, or render the reviewed revision in the background into a new subtitled video cell (the source is kept) or into the source video in place.
- `chain` — Run several existing book actions in order, passing earlier outputs to later steps with {$ref:{step_id,output}}. Steps are {id, tool, params}; ids are unique and start with a letter. Paid steps pause for review. action: run, status, cancel, or approve with chain_id and step_id to let a paused step continue.
- `change_video_speed` — Change video playback speed (speed up or slow down), for the whole clip or only a section (for example 'speed up the last six seconds' sets start_seconds to duration minus 6). Operates in-place with git versioning.
- `chat` — Route one composer request through the app's chat model: runs reads and returns reviewable plans for edits and generation. Agents should call the specific tools directly instead.

Rewrite, chat and analysis use text-call forecasts that exclude media, tools and history. Dynamically billed fal models use fal's historical average per call when FAL_ADMIN_API_KEY is set, and that estimate warns that it ignores the request.
