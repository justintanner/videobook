# Workspace action coverage

Generated by `npm run docs:commands` from the registered tools, command definitions and surface contracts. 335 active endpoints map to 406 visible actions or their owning workflows. Unknown endpoints, handlers, aliases and missing declared surfaces fail the catalog contract. Historical generation names remain outside the active catalog.

The browser regression suite checks catalog equality, complete slash traversal, typed form discovery, named target selection, menu and slash parity, review and cancellation, real media mutations and focus. Provider generation, posting and OS clipboard integration require separate execution validation; opening a form never starts a paid job or publishes content.

## Transport and workflow ownership

| Endpoint | Visible owner | Reason |
| --- | --- | --- |
| `upload_file` | `command.upload` | Import opens a native file picker and uploads media through the file workflow; users do not enter base64 data. |
| `video_goal` | `command.goal` | Goal mode plans a video, reviews all shots and runs the approved goal. |
| `assemble_goal` | `command.goal` | Goal mode appends its completed shots to the sequence in order. |
| `push_chat_history` | `tool.chat` | Compatibility write for composer history; users enter messages through chat. |
| `record_prompt` | `tool.chat` | Records text entered through the composer and generation editors; browsing history is a separate action. |
| `slash_commands` | `command.actions` | Loads slash suggestions and dynamic project shortcuts in the Actions launcher. |
| `check_duplicate_bytes` | `command.upload` | Checks existing immutable bytes during Import before uploading a file. |
| `list_workspace_actions` | `command.actions` | Loads the Actions launcher and its typed forms. |
